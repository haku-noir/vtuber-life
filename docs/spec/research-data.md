## 0. 読み方

### 0.1 区分

| 区分 | 意味 | 仕様書での表示バッジ |
| --- | --- | --- |
| 統計 | 出典が数えた・調べた値をそのまま記録したもの。定義・範囲は出典に従う | 「統計」 |
| 推定 | 複数の出典の組合せ、区間内の補間、比率の外挿など、本書側の計算を含むもの。式と入力を明記 | 「推定」 |
| 仮置き | ゲーム調整用の値。現実の値ではない | 「仮置き」 |
| 未取得 | 調べたが、定義が明確で再確認できる数字を得られなかったもの | 「未取得」 |
| 傾向（言及数） | X等で語が使われた投稿の件数。属性の人口比ではない | 第34・35章では根拠の補助としてのみ使用 |

### 0.2 信頼度

| 段階 | 目安 | 例 |
| --- | --- | --- |
| A | 企業・調査会社・プラットフォームの公表値。定義と方法が公開されている | ユーザーローカル、矢野経済研究所、YouTube、Streams Charts |
| B | 査読付き論文・学術発表。対象は限定的だが方法が明確 | CHI 2025、WWW 2025 |
| C | 個人・メディアの独自集計、少数アンケート。方法は書かれているが標本に偏りがある | 個人ブログの集計、n=67のX上アンケート |
| D | 検索結果の要約のみで本文を確認できなかった、または算出方法が確認できない | 本文取得不可のガイド記事 |

信頼度は「その出典が定義した範囲の中でどれだけ確かか」であり、「VTuber全体を代表するか」ではない。A段階でも対象範囲が狭ければ、全体の比率としては使わない。

### 0.3 取得時の制約

- ユーザーローカルの公開ランキングは1ページ50件、40ページ（2,000件）までしか表示されないため、5万人未満のチャンネル数は数えられなかった。
- FanLoopのガイド記事は取得時にHTTP 402（配信停止）となり、検索エンジンの要約しか確認できなかった。
- X APIのユーザー検索は認証方式の制約で使えなかった。投稿件数の集計（直近7日）と投稿の標本検索のみ使用した。
- 個人の小規模VTuberの投稿は、名前を記録しない。ハッシュタグ・検索式だけを出典として残す。

### 7.5 投稿の標本から読み取れたこと（質的、K05～K07）

- 一人称について、「私」「わたし」「ボク」「ウチ」「俺」「自分」「名前呼び」「おじさん」「おいら」のほか、「妾」「拙者」「朕」「某」「小生」「拙僧」等が話題に挙がる。演じる一人称と普段の一人称の違いが「つい出てしまう」ことは、活動者自身もよく話題にしている。検索式：`vtuber 一人称 -is:retweet lang:ja`（2025年4月以降、関連度順25件）。
- 自己紹介企画「#Vtuber30Day自己紹介Challenge」のお題には、名前・読み方・由来、活動場所、主な活動内容、活動時間、家族構成、誕生日・年齢・身長、モチーフとイメージカラー、ビジュアルのチャームポイント、一人称・声や話し方、活動タグ・ファンマーク・ファンネーム等がある（1～10日目を確認。11日目以降の全項目は未取得）。
- 「#種族を超えた歌枠リレー」のように、種族設定そのものを企画にした例がある。
- 個人の投稿者名は記録しない。

### 7.6 公式プロフィールの項目（P09）

hololive公式のタレントページ（例：宝鐘マリン）には、誕生日、初配信日、身長、ユニット、イラストレーター、夢、ファンネーム、ハッシュタグ（配信タグ・ファンアート）、メッセージ、趣味、好きなもの、特技、Q&A、Words/ミームの欄がある。Words/ミーム欄には、本人が数回言っただけの言葉が口癖として定着したという説明がある。これは「口癖は本人が決めるだけでなく、視聴者の受け止めで定着する」という設計の根拠に使う（第34.6節）。
